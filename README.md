# AI-Startup-Evaluator
AI Startup Evaluator is an advanced Agentic Workflow system built using LangChain &amp; LangGraph that analyzes startup ideas &amp; provides an intelligent investment assessment.  The system uses multiple agents to perform markcompetitor analysis, SWOT generation, &amp; more. It integrates RAG, &amp; web search tools to simulate a real-world AI investment analyst.
